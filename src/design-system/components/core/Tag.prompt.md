**Tag** — compact pill label for categories, statuses, and metadata.

```jsx
<Tag tone="brand">모집중</Tag>
<Tag tone="seal">41기</Tag>
<Tag tone="neutral">세미나</Tag>
```

- **Tones:** `neutral` (sunken paper), `brand` (red tint), `seal` (deep oxblood fill — the traditional stamp), `outline`.
- **Sizes:** `sm` / `md`.

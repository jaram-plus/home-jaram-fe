**Stat** — a large editorial-serif numeral with a label, for heritage figures.

```jsx
<Stat value="41" label="년의 역사" />
<Stat value="500" suffix="+" label="졸업생" />
<Stat value="1984" label="설립년도" align="left" />
```

- Numeral is set in `--font-serif` (Gowun Batang) and colored deep oxblood (`--brand-deep`) for the prestige feel.
- `suffix` renders as a small superscript (e.g. the `+` on `70+`).
